# 回合与灰盒地图工作流

## 本步目标

把训练场升级为最小攻守回合：准备阶段、3 分钟交战、目标激活、攻方胜利、防守方拖延获胜、结果展示和自动开始下一回合。

## 启用现有场景

1. 等待 Unity 编译结束。
2. 选择 `Project Sun > Add Round Loop To Combat Slice`。
3. 工具会保存并打开 `CombatSlice`，新增 `Objectives` 根节点及 `Game Systems/RoundManager`。
4. 按 Play：准备阶段结束后，进入蓝色的 Objective A 或 B 区域，按住 `F` 四秒即可取得进攻方胜利；若三分钟内未激活目标，防守方获胜。

## 灰盒地图规则

- 保持两个目标区之间存在两条主路径和一条风险更高的侧路。
- 每个目标区至少应有两条入口、一个可防守掩体和一个可被侧翼观察的位置。
- 掩体高度应有明确类型：半身、站立、不可穿透；不要在同一区域混用模糊高度。
- 出生点到目标区的抵达时间应通过实际计时验证，而不是目测。
- 每次修改道路、掩体或目标区位置后，必须分别从进攻方和防守方视角跑一遍。

## 本步验收

- HUD 始终显示当前回合状态、倒计时和目标提示。
- 目标区外按 `F` 不会产生进度；离开目标区或松开 `F` 会重置进度。
- 回合结束后目标区不可再次激活，并在结果时间结束后自动进入下一准备阶段。
- `CombatSlice` 可保存、关闭、重新打开并保持所有目标区和回合对象。

## 后续衔接

此回合逻辑当前是离线权威版本。下一步将加入机器人状态机与导航网格，用机器人验证攻守路径、视线和掩体，再把相同状态机迁移到服务端权威联机实现。
