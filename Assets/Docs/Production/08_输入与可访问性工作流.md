# 08 输入与可访问性工作流

## 当前实现

`FpsInput` 使用 Unity Input System 1.11，在运行时创建一套独立的 FPS 输入映射；游戏逻辑不再读取旧版 Input Manager 的 `Mouse X/Y` 轴。项目的 Active Input Handling 保持为 Both，因而已导入资源仍可按其原有方式工作。

玩家可以在训练场按 **O** 打开 Field Settings：

- 鼠标灵敏度：0.02–0.50；
- 视野角：70–110；
- 重绑定移动、射击、瞄准、跳跃、冲刺、下蹲、换弹、技能、交互与配件界面；
- Reset Defaults 恢复默认值。

键位覆盖、灵敏度和 FOV 保存到本机 `PlayerPrefs`，下次启动会自动恢复。按 ESC 取消一次重绑定；按 O 或 Resume 返回战斗。

## 手动验收

1. 在 `CombatSlice` 按 Play，确认鼠标视角、WASD、射击、换弹、Q/E 技能与 F 交互均正常。
2. 按 O，将 MOVE FORWARD 改为上方向键；关闭面板后确认移动立即生效。
3. 重启 Play Mode，确认该键位、灵敏度和 FOV 仍保留。
4. 用 Reset Defaults 恢复默认键位，再验证一次。

## 后续产品化要求

当前面板是原型级 IMGUI 表现层，输入服务与 UI 已分离。正式版应迁移为 UGUI 或 UI Toolkit，增加鼠标反转、独立 ADS 灵敏度、手柄布局、冲突检测、本地化和云端配置同步；多人模式中只同步服务器认可的游戏行为，不同步本地按键设置。
