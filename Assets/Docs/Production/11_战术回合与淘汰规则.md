# 11 战术回合与淘汰规则

## 离线战术规则

CombatSlice 的训练循环现在采用不可重生的短回合：

- 准备阶段：玩家与 Defender 均重置到出生点，Defender 不会攻击；
- 活跃阶段：激活 A/B 目标；
- 进攻方胜利：成功激活目标，或消灭所有 Defender；
- 防守方胜利：时间耗尽，或玩家被消灭；
- 结果阶段：冻结战斗输入和 Defender，计时结束后开始下一次准备。

这使目标、击杀和掩体选择都影响同一回合结果，而不是被训练场自动重生掩盖。

## 验收

1. 进入活跃回合后被 Defender 击杀，HUD 显示 `DEFENDERS WIN` 与 `ATTACKER ELIMINATED`；玩家不应在本回合复活。
2. 消灭三台 Defender，HUD 显示 `ATTACKERS WIN` 与 `DEFENDERS ELIMINATED`。
3. 激活目标或等待倒计时结束，分别验证原有进攻方/防守方胜利。
4. 等待结果计时结束，确认玩家与三台 Defender 以满生命重置，Defender 仅在下一活跃回合开始攻击。

## 联机边界

单机 `RoundManager` 仅为战术验证服务。多人版本中，回合状态、击杀、复活资格和胜负必须由服务器权威决定；客户端只展示服务器下发的状态和结果原因。
