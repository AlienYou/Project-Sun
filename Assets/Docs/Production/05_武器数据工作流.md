# 武器与配件数据工作流

## 本步目标

让武器和配件数值成为 Unity 的 ScriptableObject 资产，而不是写死在 UI 或玩法脚本中。这样策划可以调整数值，程序不需要重新编译；后续联机时服务端也可以使用同一份定义进行校验。

## 首次生成

1. 等待 Unity 编译完成。
2. 选择 `Project Sun > Generate Combat Weapon Data`。
3. 工具会保存 `CombatSlice`，并创建如下资产：

```text
Assets/_ProjectSun/Data/Weapons/
  Definitions/AR4Carbine.asset
  Attachments/*.asset
  Catalogs/AR4LoadoutCatalog.asset
```

已存在的武器和配件资产不会被覆盖；重新执行菜单仅重新整理目录中的可用配件列表。

## 编辑规则

- 在 `AR4Carbine.asset` 中修改基础伤害、射速、弹匣、换弹、散布和射程。
- 在单个配件资产中只填写乘数。`1` 表示不改变，`0.8` 表示减少 20%，`1.2` 表示增加 20%。
- 同一槽位只能装备一个配件；UI 会替换旧项而不是累加同槽位效果。
- 不允许零或负的伤害、射速、弹匣、换弹时长和射程。数值变更必须在训练场验证后才可进入对局。

## 验证

打开 `CombatSlice` 并按 Play，按 `Tab`：

1. 面板标题显示 `AR-4 CARBINE`。
2. 点击任意配件，右侧统计立即改变。
3. 装备扩容弹匣后，装填完成时弹药量与新弹匣容量一致。
4. 停止、重新启动 Play Mode 后，基础枪械与可选配件仍然可用。

## 商业化边界

客户端 ScriptableObject 仅用于展示、预测和离线模式。未来联机对局中，玩家提交的“武器 ID + 配件 ID”必须由服务端根据受控目录重建并验证，不能相信客户端传来的伤害或射速数值。
