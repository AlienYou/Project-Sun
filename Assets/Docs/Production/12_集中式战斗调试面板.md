# 12 集中式战斗调试面板

## 目的

按 F10 打开仅供开发使用的 Combat Debug Dashboard。它将玩家、回合、Defender 状态和物理射线集中到一个面板，避免依赖零散的 Console 输出。

## 面板内容

- 玩家：生命、位置、移动输入、输入是否冻结、最近伤害来源；
- 回合：当前状态、倒计时、胜负原因、存活 Defender 数；
- Defender：生命、状态（STANDBY/PATROL/CHASE/FIRE/ELIMINATED）、距玩家距离和最近射线结果；
- Ray Records：玩家与各 Defender 实际命中的 Collider、Layer 及 BLOCKED/VISIBLE/DAMAGE APPLIED 结果。

## 使用规则

1. 在 Unity Editor 或 Development Build 中按 F10 开关面板。
2. 排查掩体问题时，确认同名 Defender 的状态、Ray Records 和 HUD 伤害来源一致。
3. Release 构建不启用面板和射线绘制；不得把此面板作为正式玩家 UI。
