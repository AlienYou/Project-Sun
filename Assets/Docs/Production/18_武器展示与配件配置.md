# 武器展示与配件配置

## 目标

将第一人称视觉表现与武器伤害、射速、弹匣等玩法数值分离。武器本体提供稳定的默认展示姿势；配件只提交自己的增量或覆盖项。

```
WeaponDefinition + WeaponAttachment（玩法数值）
                 + WeaponPresentationProfile（腰射、后坐力、默认 ADS）
                 + Optic ADS Profile Override（可选）
                 -> 运行时武器表现
```

## AR-01 基准资产

- `Data/Weapons/Presentation/WPP_AR01`：AR-01 的第一人称展示基准。
- `Data/Weapons/ADS/ADS_AR01`：AR-01 默认机械瞄具的校准数据。
- `Data/Weapons/Attachments/*`：已有的可装备配件定义。

`WPP_AR01` 控制腰射位置、腰射旋转和基础镜头后坐力倍率。它引用默认 ADS Profile；因此校准机瞄时仍使用 ADS Workbench，调整腰射画面时则编辑 WPP。

## 新武器流程

1. 复制一份 `WPP_AR01`，命名为 `WPP_<WeaponId>`。
2. 为该武器的机械瞄具创建 `ADS_<WeaponId>_Iron`，并在 ADS Workbench 校准。
3. 将 ADS Profile 填入 WPP 的 `Default Ads Profile`。
4. 将 WPP 赋给该武器的 `LowPolyShooterViewmodelRig`（或之后的同类视模型 Rig）。
5. 在游戏中确认腰射完整枪身、ADS 对齐、开火和贴墙姿势。

## 新瞄具流程

1. 创建或复制一个 `WeaponAttachment`，Slot 设为 `Optic`。
2. 为瞄具对应的视觉模型创建并校准独立 ADS Profile。
3. 将其填入 Attachment 的 `Ads Profile Override`。
4. 装备该配件后，运行时会使用该瞄具的 ADS Profile；未提供覆盖项的配件会继续使用武器默认机瞄。

只有在瞄具模型、Aim Anchor 和枪口轴线已经正确绑定后，才应填写 ADS 覆盖。没有视觉模型的原型配件保持为空即可。

## 其他配件

- 枪托、握把、枪管等可使用 `Hip Camera Space Position/Rotation Offset` 做很小的叠加修正。
- `View Kick Multiplier` 控制配件对镜头与根节点后坐力的整体倍率。
- 伤害、射速、扩散等字段仍由同一个 Attachment 的玩法倍率控制。

配件应只写增量，不复制整套武器参数。这样替换配件不会破坏武器本体的机瞄校准，也利于以后组合、存档和网络同步。
