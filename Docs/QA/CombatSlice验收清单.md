# CombatSlice 阶段回归验收清单

本清单用于原型工作包完成后的短 Play Mode 冒烟。专项制作规范中的详细测试仍然有效，但除非改动触达对应系统或正在执行 Gate 4 正式签字，当前阶段不要求把所有条目逐项执行和归档。

## 原型阶段最低门禁

- 修改 C# 后确认脚本能够编译，Console 没有阻断本次验证路径的项目错误。
- 打开 `CombatSlice` 进入 Play Mode，实际运行本次改动直接涉及的功能；不相关系统无需重复全量回归。
- 至少完成一次准备、交战和回合结算；若改动涉及死亡、观战或重置，再继续验证到下一准备阶段。
- 检查本次修改的场景、Prefab、配置资产和 `.meta`，确认没有 Missing Script、丢失引用或意外覆盖人工调整。
- 在任务卡或提交说明中记录“通过/失败”、阻断问题和已知风险即可；当前不强制截图、视频、Player Log、故障注入或 Windows 构建报告。

## 启动与 Console

- 打开 `Assets/_ProjectSun/Scenes/CombatSlice.unity`，等待编译结束后进入 Play Mode。
- 场景只有一个本地玩家、一个有效世界相机链和一个 HUD；Console 不出现新的红色错误、空引用或重复 AudioListener 警告。
- 双方名册最多各 6 人，出生位置和 HUD 槽位一致，没有成员重叠、卡墙或落在 NavMesh 外。

## 回合与配装

- 准备阶段可以选择主武器、副武器、兼容配件和战术装备；战斗开始后配装被锁定。
- 战斗阶段不能局中复活；任一方全灭只结算一次，比分正确增加，先赢 7 回合进入比赛完成状态。
- 结果展示后进入新准备阶段，生命、弹药、装备次数、Bot、出生点和玩家输入均正确重置。
- `F8` 能快速重开开发测试并清零比分；Release 流程不得依赖该快捷键。

## 武器与附件

- 主副武器切换、收枪/拔枪、开火、换弹、ADS 和动画姿态与当前武器匹配。
- 腰射和 ADS 下枪身构图合理；Clip Probe 没有未解释的失败，贴墙姿势和枪口阻挡均生效。
- 相机中心确定瞄准目标，枪口路径被墙阻挡时只命中墙；墙后角色不受伤，墙体命中不显示角色命中标记。
- 当前装备的瞄具与其 ADS Profile、AimAnchor 和 LensAnchor 匹配；倍率镜的镜内画面、准星、镜外弱化及快速开关镜没有错位或黑屏。

## 输入、HUD 与观战

- 移动、视角、射击、换弹、技能、战术装备和主副武器选择均使用 Input System；设置菜单改键能够保存并恢复。
- HUD 的生命、弹药、武器、装备、阵营、存活人数、比分和计时与权威状态一致。
- 本地玩家死亡后，第一人称枪模和瞄具表现消失，只能循环观看己方存活队友；左右切换、目标死亡自动切换和相机防穿墙正常。
- 死亡或准备阶段打开并关闭设置菜单，不会错误恢复移动、射击、换弹、技能或战术装备输入。
- 全队淘汰后观战画面保持稳定；下一回合准备阶段恢复第一人称 Camera、AudioListener、HUD 和正常输入流程。

## 资源与提交

- 所有新增或修改的 Unity 资源都带有对应 `.meta`，没有 Missing Script、Missing Material 或丢失序列化引用。
- 正式运行时引用位于 `Assets/_ProjectSun`；第三方来源和许可证已更新到资产授权台账。
- 提交前核对 `git diff`，避免把无关的 Workbench 校准资产、用户场景调整或自动生成目录一起提交。
