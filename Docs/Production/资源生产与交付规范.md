# 资源生产与交付规范

状态：现行。本文与[资产授权台账](../Compliance/资产授权台账.md)共同构成外部资源进入正式项目目录的门禁。

## 目的

本规范把项目资源分成两类：用于验证玩法的原型资源，以及已经完成授权、性能和风格验收的正式资源。原型资源不能因为“已导入”而自动进入可发布版本。

## 目录边界

```text
Assets/
  _ProjectSun/Art/              # 项目正式拥有或已获准发布的美术资源
    Characters/                 # 角色、第一人称手臂、动画
    Weapons/                    # 武器模型、动画、配件视觉资源
    Environment/                # 模块化地图、道具、植被
    Materials/                  # 正式材质与材质实例
    Textures/                   # 共享贴图、贴图集
    VFX/                        # 枪口火焰、命中、技能特效
    Audio/                      # SFX、环境音、音乐
    UI/                         # 图标、字体、界面图形
  _ProjectSun/Prefabs/          # 只存可复用的项目预制体
  _ProjectSun/Data/             # 武器、配件、技能等数据资产
  _ProjectSun/Art/ThirdParty/   # 经筛选的运行时第三方副本，并保留对应第三方声明
  ThirdParty/                   # 新导入外部资源的可选暂存目录；保持原始结构，不直接修改
Docs/Compliance/                # 仓库级资产授权台账；不放入 Unity AssetDatabase
```

现有 `Assets/Art`、`Assets/Infima Games`、`Assets/Low Poly Weapons VOL.1`、`Assets/LowPolyFPSLite` 与 `Assets/LowPolyWeapons_LITE` 保持原位置，统一视为来源目录或待核验原型资源，不得直接成为正式运行时依赖。已经通过迁移工具复制到 `_ProjectSun/Art/ThirdParty` 的运行时副本仍受原许可证约束，迁移本身不等于取得所有权或发布许可。

## 资源进入正式目录的流程

1. **需求卡**：明确用途、所属关卡/武器/技能、预算、目标平台和性能预算。
2. **来源审查**：在[资产授权台账](../Compliance/资产授权台账.md)填写来源、作者、许可、下载日期和商业分发条件。
3. **导入检查**：确认 Unity 2022.3 + URP 兼容性、比例、材质、碰撞、动画与音频导入设置。
4. **技术验收**：检查贴图尺寸、模型面数、LOD、Draw Call、内存和移动端以外的 Windows 目标帧率影响。
5. **内容验收**：检查近未来工业设施的风格、敌我辨识、可读性和与玩法的匹配度。
6. **登记发布**：审核状态变为“已批准”后，才能进入 `_ProjectSun/Art` 和可发布构建。

## 首个可玩版本的资源优先级

1. 第一人称手臂，以及持枪、开火、换弹、切枪动画。
2. 两把主武器、一把副武器和 4–6 个外观可区分的配件。
3. 枪声、脚步、换弹、命中、死亡和技能提示音。
4. 一套工业设施模块化地图件：地面、墙体、门、掩体、双方出生区和小型道具；爆破目标点资源留到对应模式立项后制作。
5. 烟雾、闪光、侦测等技能的 VFX 与 UI 图标。
6. Defender 和玩家的受击、死亡与阵营识别资源。

## 技术基线

- Unity 世界单位使用米；模型在导入前冻结不需要的缩放，Prefab 根节点保持 `Scale = (1, 1, 1)`。
- 正式武器、角色和大型道具需要碰撞策略与 LOD；灰盒资源可豁免，但必须标注 `Prototype`。
- 贴图按用途命名并使用平台适当压缩；避免为小型道具使用 4K 贴图。
- 音频统一记录来源与许可，长音频和音乐需额外记录循环点、响度和混音分类。
- 外部原始下载包、采购凭证、源文件和许可原文保存在项目仓库外的受控归档中；仓库内保留可审计的台账和必要第三方声明。
- 大型二进制源文件进入版本管理前，先评估 Git LFS；不要提交 Unity 的 `Library`、`Temp` 或构建产物。

## 资源完成定义（Definition of Done）

- 台账记录完整，商业使用与再分发条件已审核。
- 文件、Prefab、材质和命名符合目录边界。
- 在目标 URP 设置下无缺失 Shader、材质或引用。
- 有可接受的性能数据，且不影响训练场的战斗可读性。
- 已在至少一个实际场景和目标交互中验证。
