# 09 射击反馈与性能验收

## 当前实现

`WeaponFeedbackController` 是纯客户端表现层，监听 `HitscanWeapon.Fired`，不会修改伤害、散布、射速或联机时需要由服务器确认的状态。

- 每次射击触发受限的垂直/水平视角后坐力；
- 第一人称枪模产生后坐与回正，按住瞄准会平滑进入 ADS 位置和 FOV；
- 枪口使用一个可复用的短时点光源，不会每发子弹创建新的 Light；
- 所有命中生成短时弹着点；仅对可受伤害目标显示 HUD 命中标记；
- 曳光材质改为共享实例，避免连射时持续创建材质。

## 验收步骤

1. 打开 `CombatSlice` 并进入 Play Mode，连续射击墙体和 Defender。
2. 确认两者都有弹着点，只有 Defender 受击时准星中心出现命中标记。
3. 按住右键，确认枪模/FOV 平滑进入瞄准状态；松开后平滑恢复。
4. 连续射击 30 秒，在 Unity Profiler 的 Memory 视图确认材质数量不会随射击次数线性增长。

## 联机边界

后坐、FOV、命中标记和弹着视觉都可以由客户端预测；伤害、命中确认和弹药扣减在多人版本必须以服务器结果为准。客户端只能根据服务端确认事件显示最终命中标记。
