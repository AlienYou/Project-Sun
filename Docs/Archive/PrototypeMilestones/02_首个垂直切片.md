# 首个垂直切片规格 v0.1

## 目标

交付一个可在 Windows 上独立测试 10 分钟的单机攻守训练切片。玩家能进入训练场、移动、射击、切换两种技能、修改枪械配件、对抗机器人，并在回合结束时得到明确结果。

这个切片的作用是验证核心枪战，而不是堆积内容。它通过后，所有后续枪、角色、地图和网络功能都复用相同的数据与接口。

## 玩家体验流程

1. 启动游戏，进入主菜单。
2. 选择“训练对局”，加载工业训练地图。
3. 在准备阶段选择主武器与配件。
4. 进入 3 分钟攻守回合，与 3 个机器人交战并完成目标。
5. 回合结束后显示胜负、命中率、击杀/死亡、伤害、技能使用和性能摘要。
6. 返回菜单或重新开始；不需要重启程序。

## 可验收功能

| 范围 | 验收条件 |
| --- | --- |
| 输入 | 鼠标键盘操作、灵敏度、FOV、完整按键重绑可在菜单修改并保存 |
| 移动 | 行走、冲刺、跳跃、蹲伏和地面判定稳定，不可通过常规输入穿墙或飞天 |
| 武器 | 开火、换弹、瞄准、后坐力、散布、命中、伤害、弹药与声音反馈一致 |
| 配装 | 五个配件槽互斥、可预览数值变化、进入对局后锁定；客户端以后不得任意篡改 |
| 技能 | 冲刺与专注各有冷却、明确音画反馈和反制规则 |
| 敌人 | 至少三类行为：巡逻、发现/交战、掩体移动；死亡、重生或回合结算正确 |
| 回合 | 准备、进行、结束和重开状态明确；胜负规则和 HUD 一致 |
| 地图 | 有两条主路径、一条风险更高的侧路、两个目标区域和清晰的出生保护 |
| 质量 | 连续 10 分钟运行无控制台错误；目标机 1080p 中画质不低于 60 FPS |

## 不属于这个切片

- 真实 5v5 联机、匹配、排位、反作弊和账号系统。
- 皮肤商城、战令、货币、赛季或复杂成长体系。
- 多张地图、多角色、多语言配音。

## 当前工作顺序

1. 将运行时代码创建的训练场改为可编辑的场景和预制体。
2. 用 Input System 替代旧 Input Manager，并实现可保存的按键重绑。
3. 建立武器、配件、技能的 ScriptableObject 数据资产与验证规则。
4. 完成一张灰盒地图、目标区与回合状态机。
5. 接入基础机器人、音效/VFX、菜单和结果面板。
6. 用 PlayMode 测试、性能采样和缺陷清单验收。

## 完成定义

一名未参与开发的测试者无需口头说明，即可在五分钟内启动训练对局、配装、完成一回合，并理解自己的胜负和下一步操作。若不能满足这条，切片不算完成。
