# Project Sun 产品立项 v0.1

状态：已确认。本文是后续玩法、资源、代码和采购决策的范围基线；任何会改变本文核心条目的改动，都要先记录原因和代价。

## 产品定义

| 项目 | 决定 |
| --- | --- |
| 类型 | 第一人称、回合制、团队战术射击游戏 |
| 首发平台 | Windows / Steam |
| 核心模式 | 5v5 攻守对抗，以区域控制与装置目标驱动回合胜负 |
| 美术方向 | 近未来工业设施；强调可读性、真实比例、低视觉噪声 |
| 操作方式 | 键盘鼠标优先；手柄在正式版评估 |
| 首发语言 | 简体中文、英文 |
| 引擎 | Unity 2022.3.51f1c1 LTS + URP |
| 联机原则 | 服务端权威；客户端不拥有伤害、命中确认、经济或胜负裁决权 |

## 产品支柱

1. 枪战优先：命中、后坐力、声音、动画和网络反馈必须清晰且可靠。
2. 可反制技能：技能只创造战术选择，不替代枪法；每个技能都必须有可预判、可躲避或可打断的应对方式。
3. 识别性：敌我轮廓、攻击方向、交战距离和掩体边界应在一眼内可读。
4. 可组合配装：配件改变明确的战术取舍，而非单纯叠加数值。
5. 竞技可信度：公平匹配、反作弊、断线恢复、性能稳定和可复盘性属于核心功能。

## 不做什么

- 不在首发版制作开放世界、大逃杀、载具战斗或无限成长数值系统。
- 不把真实世界品牌、武器型号、部队标志或未经许可的素材直接用于商业版本。
- 不在服务端权威与基础反作弊之前开放排位或付费竞争优势。
- 不为了功能数量牺牲 60 FPS 目标、清晰 HUD 或可维护的资源规范。

## 第一版范围

首个商业可玩版本（不是最终正式版）应包含：

- 1 张工业设施地图，支持攻守路径、两个目标区域和可验证的掩体/视线设计。
- 2 把主武器、1 把副武器、2 个通用技能和 4 至 6 个配件。
- 1 套可用角色动作、完整的开火/换弹/受击/死亡表现。
- 训练场与离线机器人对局，用于在联网前反复调校手感。
- 中英文设置、按键重绑、音量设置、图形预设、暂停与错误提示。

## 商业质量底线

在目标配置电脑上，1080p 中画质必须稳定达到 60 FPS；不得有阻断对局的崩溃、存档损坏、无限加载或可稳定复现的伤害不同步问题。每项外部资产需有来源、许可证、作者、下载日期和用途记录。

## 当前结论

当前工程的运行时训练场和枪械系统仅作为玩法原型。下一阶段将把它们改造成可编辑的预制体、数据资产和单机对局流程；联机实现将在单机切片通过枪战验收后开始。
